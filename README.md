# one-chart-2 — Film festivals vs. Oscars

Data-viz project comparing film-festival programming with Oscar nominations/wins,
culminating in a single chart (`output/chart-final.*`).

## Pipeline

Run the notebooks in order from the `notebooks/` directory:

1. `notebooks/1-clean.ipynb` — cleans the raw Oscars + festival data and writes
   the processed tables in `data/processed/`.
2. `notebooks/2-analyze.ipynb` — reads `data/processed/nomination_pct_wide.csv`
   (Python + R) and renders the chart to `output/`.

`notebooks/scraper.ipynb` scrapes IMDb festival lists (2019–2025) into
`data/scraped/`. It's a standalone data-collection step, not part of the main run.

## Folder layout

```
notebooks/    analysis + scraper notebooks (run from here)
data/
  raw/        original source data (oscars.csv, film-dataset, festival addendum)
  scraped/    IMDb scraper output (all_scraped.csv, imdb_list.csv)
  processed/  generated by 1-clean.ipynb (*_cleaned.csv, nomination_pct_*.csv)
output/       final chart exports (chart-final.*, tiff_chart.*)
archive/      old / experimental files kept for reference
```

## Notes

- Raw inputs: `data/raw/1_film-dataset_festival-program_wide.csv` and
